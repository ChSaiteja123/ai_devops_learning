09. AI Service on Kubernetes

Deploy an AI API with replicas, resource controls, and readiness checks.

Purpose

Use Kubernetes primitives to run an AI service behind a ClusterIP Service and prepare it for controlled rollout.

Workflow

Build approved image -> deploy replicas -> readiness check -> observe -> scale or rollback

Run

kubectl apply -f deployment.yaml kubectl apply -f service.yaml kubectl get pods
[PRODUCTION] Add authentication, network policy, secret references, autoscaling, cost limits, and model-specific GPU planning before production.
