08. Secure RAG Assistant

Retrieve approved local documents with source citations and safe fallbacks.

Purpose

Learn the RAG flow without an external provider: load documents, filter by tenant, retrieve relevant context, and return source IDs.

Workflow

Question -> permission filter -> retrieval -> approved context -> answer + citations

Run

python rag_assistant.py "How do I deploy safely?"
[SECURITY] Authorization happens before retrieval. Retrieved documents are data, not instructions, and must be tested for prompt injection.
