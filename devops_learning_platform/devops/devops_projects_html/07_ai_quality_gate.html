07. AI Quality Gate

Validate structured AI findings and publish an evaluation report from Jenkins.

Purpose

This dependency-free project demonstrates how AI output becomes a tested CI artifact instead of being trusted automatically.

Workflow

Mock or provider response -> schema validation -> severity checks -> JSON report -> Jenkins artifact

Run

python evaluator.py
[SECURITY] Validate model output, keep provider keys out of source control, and require human approval for high-impact actions.
