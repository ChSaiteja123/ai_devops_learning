05. Monitoring Stack

Run Prometheus and Grafana for local metrics exploration.

Purpose

Learn scrape configuration, dashboards, metrics, and the difference between collecting a signal and making it actionable.

Workflow

Compose up -> Prometheus scrapes -> Grafana queries -> operator investigates

Run

docker compose up -d # Prometheus: http://localhost:9090 # Grafana: http://localhost:3000
[SECURITY] Change default credentials and protect monitoring endpoints before shared or production use.
