12. Automated Deployment Pipeline

Promote immutable images, verify rollouts, smoke-test services, and protect production with approval.

Deployment flow

Validate -> build -> push immutable image -> deploy staging -> rollout status -> smoke test -> approval -> deploy production -> monitor -> rollback if required

Safe local dry run

python deploy.py --environment staging --image registry.example.com/app:1.0.0

The default mode prints the planned kubectl commands. Add --execute only from a trusted deployment agent with the correct cluster credentials.

[SECURITY] Use separate staging and production service accounts, least-privilege RBAC, immutable image digests, and an approval gate for production.
[PRODUCTION] Verify readiness, run a real smoke test, record the deployment evidence, and keep the previous revision available for rollback.

Jenkins stages

Validate -> Deploy staging -> Approve production -> Deploy production kubectl rollout status deployment/app --timeout=120s kubectl rollout undo deployment/app
