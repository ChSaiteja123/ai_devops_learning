15. Argo CD GitOps

Reconcile Kubernetes environments from reviewed Git history.

GitOps flow

Pull request -> merge to protected branch -> Argo CD detects change -> sync -> health check -> drift correction

Application behavior

The Argo CD Application points to a repository and path, then targets a cluster namespace. Automated sync applies approved Git state, pruning removes deleted resources, and self-healing corrects manual drift.

[PRODUCTION] Protect the repository branch, restrict allowed source repositories and destinations, review generated manifests, and audit Argo CD permissions.

Apply and inspect

kubectl apply -f project-settings.yaml kubectl apply -f application.yaml kubectl -n argocd get applications argocd app get platform-api argocd app sync platform-api
