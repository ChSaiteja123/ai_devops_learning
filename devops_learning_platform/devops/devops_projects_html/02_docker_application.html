02. Docker Application

Package and run a small Python HTTP service as a container.

Purpose

Learn how a Dockerfile creates an immutable image and how Compose runs the service with a stable port mapping.

Workflow

app.py -> Dockerfile -> docker build -> docker run -> HTTP response

Run

docker build -t devops-python-app . docker run --rm -p 8000:8000 devops-python-app # or docker compose up --build
[SECURITY] Use trusted minimal base images, scan images with Trivy, and never bake credentials into the image.
