01. CI/CD Pipeline

Automate Python testing with Jenkins or GitHub Actions.

Purpose

This project demonstrates checkout, dependency installation, testing, and test-report publication as repeatable pipeline stages.

Workflow

Commit -> checkout -> install pytest -> run tests -> publish report

Key files

Jenkinsfile: declarative Jenkins pipeline. test_smoke.py: test target. .github/workflows/ci.yml: GitHub Actions alternative.

Run

python -m py_compile test_smoke.py python -m pytest -q
[PRODUCTION] Keep credentials in Jenkins or GitHub secret stores and protect production environments with approvals.
