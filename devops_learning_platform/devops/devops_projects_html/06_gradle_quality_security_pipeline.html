06. Gradle Quality and Security Pipeline

Combine Jenkins, Gradle, SonarQube, Trivy, Prometheus, and Alertmanager.

Purpose

Build and test a Java application, enforce code quality, scan files and images, then monitor the surrounding platform.

Workflow

Checkout -> Gradle test -> SonarQube -> Trivy filesystem -> Docker build -> Trivy image -> deploy

Required tools

JDK 17, Gradle 8, Jenkins, SonarQube, Docker, Trivy, Prometheus, and Alertmanager.

[SECURITY] Store SonarQube tokens and registry credentials in Jenkins credentials. Fail releases on agreed HIGH and CRITICAL findings.
