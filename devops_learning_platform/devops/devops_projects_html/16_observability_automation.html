16. Observability Automation

Validate, group, deduplicate, route, and audit Prometheus and Alertmanager events.

Automation flow

Prometheus rule -> Alertmanager -> webhook -> validate -> deduplicate -> group by severity -> choose receiver -> generate notification plan -> audit and notify

Local run

python alert_router.py sample-alerts.json

The sample contains a duplicate fingerprint. The router keeps one unique alert, records the duplicate count, and creates separate critical and warning routes without sending real notifications.

[IMPORTANT] Grouping and deduplication prevent alert storms, but every group still needs an owner, runbook, escalation path, and response deadline.
[SECURITY] Authenticate webhook requests, redact sensitive labels, and never execute remediation directly from an alert payload.

Prometheus and Alertmanager

Prometheus evaluates alerts. Alertmanager groups related alerts and selects a receiver. The router validates the payload and writes an auditable plan. A separate authorized workflow decides whether any action is allowed.

Jenkins validation

python3 -m py_compile alert_router.py python3 alert_router.py sample-alerts.json assert duplicate_count == 1 assert unique_alert_count == 2
