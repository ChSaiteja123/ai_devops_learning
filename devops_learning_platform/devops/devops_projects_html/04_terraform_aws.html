04. Terraform AWS Foundation

Describe a small AWS VPC with infrastructure as code.

Purpose

Create a VPC, public subnet, Internet Gateway, route table, and association through reviewed Terraform configuration.

Workflow

terraform init -> terraform fmt -> terraform validate -> terraform plan -> review -> apply

Run

terraform init terraform fmt -check terraform validate terraform plan
[WARNING] Review the plan and confirm AWS credentials, region, cost, and destroy behavior before applying.
