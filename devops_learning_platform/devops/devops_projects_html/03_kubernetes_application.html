03. Kubernetes Application

Run a replicated container workload behind a Kubernetes Service.

Purpose

Understand Deployments, Services, replicas, readiness probes, and resource requests/limits.

Workflow

Build image -> publish image -> apply Deployment -> apply Service -> inspect pods

Run

kubectl apply -f deployment.yaml kubectl apply -f service.yaml kubectl get pods kubectl get service devops-python-app
[PRODUCTION] Use immutable image tags, network policies, secret references, probes, resource limits, and controlled rollouts.
