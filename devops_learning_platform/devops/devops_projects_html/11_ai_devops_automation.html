11. AI DevOps Incident Automation

Classify alerts, recommend safe next steps, and publish an auditable incident report.

Purpose

This project demonstrates AI-assisted incident triage without allowing a model to make destructive production changes automatically.

Workflow

Alert JSON -> validate -> rank severity -> summarize -> recommend bounded actions -> audit report

Run locally

python automation.py alerts.json

The command creates incident-report.json with priorities, summaries, recommended actions, and an explicit automated_action_taken value.

[SECURITY] The project only recommends actions. Keep authorization, rollback execution, credentials, and production changes outside the model and require human approval for high-impact operations.
[PRODUCTION] Add PagerDuty, Slack, ticketing, redaction, immutable audit storage, rate limits, and evaluation cases before connecting real integrations.

Jenkins automation

stage('Validate automation') { steps { sh 'python3 -m py_compile automation.py' sh 'python3 automation.py alerts.json' } } post { always { archiveArtifacts artifacts: 'incident-report.json' } }

Learning outcomes

This project teaches structured alert ingestion, validation, priority classification, safe AI boundaries, deterministic fallbacks, CI artifact publication, and incident auditability.
