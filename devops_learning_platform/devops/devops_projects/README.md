# DevOps Projects

Each project is isolated in its own folder so it can be studied, tested, and extended independently.

## Basic Projects

1. `01_cicd_pipeline`: Jenkins pipeline for a Python application, with GitHub Actions alternative
2. `02_docker_application`: Dockerfile and Compose configuration
3. `03_kubernetes_application`: Kubernetes Deployment and Service manifests
4. `04_terraform_aws`: Terraform structure for an AWS VPC
5. `05_monitoring_stack`: Prometheus and Grafana starter configuration

## Intermediate Projects

6. `06_gradle_quality_security_pipeline`: Jenkins, Gradle, SonarQube, Trivy, Prometheus, and Alertmanager
7. `07_ai_quality_gate`: deterministic AI output validation and Jenkins quality gate
8. `08_secure_rag_assistant`: local retrieval assistant with source citations and tenant filtering
9. `09_ai_service_kubernetes`: Kubernetes deployment and service for an AI API
10. `10_ai_observability`: Prometheus metrics and alert rules for AI services
11. `12_auto_deployment_pipeline`: staged Kubernetes deployment with rollout verification and approval
12. `13_kubernetes_management`: namespace, RBAC, quotas, policies, scaling, and rollout management
13. `18_html_devops_dashboard`: hands-on HTML, CSS, and JavaScript operations dashboard

## Advanced Projects

13. `11_ai_devops_automation`: AI-assisted incident triage and safe remediation planning
14. `14_istio_service_mesh`: traffic routing, canary splits, mTLS, and authorization policy
15. `15_argocd_gitops`: declarative Kubernetes delivery with sync, pruning, and self-healing
16. `16_observability_automation`: alert validation, deduplication, routing, and audit planning
17. `17_end_to_end_ai_automation`: alert-to-analysis-to-policy-to-deployment audit workflow

Read the README inside each project before running it.

For a visual explanation of every project, open `../devops_projects_html/index.html`.
