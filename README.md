# Visual AI Learning Paths

This folder contains three self-paced, ten-day learning paths and an integrated 90-day course covering Generative AI, Agentic AI, and AI DevOps. Daily lessons use separate folders and accessible SVG diagrams. Agentic AI and AI DevOps lesson folders use concept names; the Generative AI short path retains numbered day folders. The 90-day course also uses concept-named lesson folders while its pages and navigation retain the day number, and includes weekly notes for all 13 weeks.

## Start here

Open [`index.html`](index.html) and choose a path:

- [Generative AI](generative-ai/index.html): tokens, transformer concepts, prompts, sampling, retrieval, multimodal systems, evaluation, and responsible release.
- [Agentic AI](agentic-ai/index.html): agent loops, tool contracts, state, planning, trust boundaries, approvals, testing, monitoring, and safe architecture.
- [AI DevOps](ai-devops/index.html): AI-assisted engineering, CI, staged releases, observability, MLOps, LLMOps, reliability, and governance.
- [Integrated 90-day course](90-day-course/index.html): daily deep dives across all three topics, weekly synthesis and retrieval practice, printable note prompts, and an integrated capstone.

Each daily lesson includes a visual explanation, concept deep dive, fictional exercise, safety/reliability guidance, mastery checkpoint, and note-taking prompts. Weekly notes add outcomes, review questions, a lab, and synthesis space. No external model, API, cloud account, dependency, or production system is required.

## Regenerate the HTML pages

The 30 short-path pages are generated by [`build_visual_lessons.py`](build_visual_lessons.py); the 90-day course is generated by [`build_90_day_course.py`](build_90_day_course.py). Both use the Python standard library. Run these commands from this folder:

```powershell
python build_visual_lessons.py
python build_90_day_course.py
```

The first script writes the hub, three track indexes, and 30 daily pages. Agentic AI and AI DevOps use concept-named lesson folders; Generative AI uses `day-XX` folders. The second script writes the 90-day course index, 13 weekly note pages, and 90 concept-named lesson folders. Both generators preserve the day number in lesson headings and navigation.

## Validate

From this folder:

```powershell
python -m unittest discover -s tests -v
```

All diagrams and exercises are illustrative. Agent and operations examples use mock, bounded flows; they do not execute tools, connect to infrastructure, or authorize real changes.
