LLMOps: prompt, model, and retrieval lifecycle

Version and evaluate the full application configuration, not just the model name.

Visual explanation

Deep dive

Version the effective system

Record prompt templates, model/provider version, decoding parameters, retrieval corpus and index, parsers, and policy. A model name alone cannot reproduce application behavior.

Build regression sets

Include grounded answers, no-answer cases, conflicting sources, structured-output failures, sensitive-input handling, and prompt injection. Score with reviewed criteria and preserve representative failures.

Monitor updates and dependencies

Provider changes, corpus refreshes, and embedding/index rebuilds can change behavior without application code edits. Track rollout versions, freshness, quality, latency, and cost.
