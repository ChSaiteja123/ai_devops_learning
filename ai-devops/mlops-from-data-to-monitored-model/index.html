MLOps: from data to monitored model

Visualize reproducible model training, validation, promotion, and monitoring.

Visual explanation

Deep dive

Track lineage

Record dataset versions, code, dependencies, configuration, random seeds where relevant, and model artifact identity. Provenance helps reproduce a result and investigate change.

Validate before promotion

Check data quality, leakage, baseline performance, appropriate splits, subgroup behavior, and deployment compatibility. A strong offline metric can still fail on changed real-world inputs.

Monitor after release

Watch service health, input drift, outcome quality when labels arrive, fairness concerns, and resource use. Define owners and thresholds for investigation, rollback, or a separately reviewed retraining cycle.
